# 末日4056

一款俯视角 3D 类幸存者肉鸽网页游戏，是我们小组的作业项目。玩家在辐射不断升高的废墟城市里一路突围，用沿途捡到的枪械和子弹组装武器，在安全屋里整备升级，最后击败尸王。支持单人游戏和局域网 1~4 人联机。

## 游玩

- **在线试玩**（仅单人）：<https://alone03125.github.io/Game4056/>
- **本地游玩**：安装 [Node.js](https://nodejs.org/) 后，在项目目录依次运行下面两条命令，然后双击打开 `dist/Game4056.html`。

```bash
npm install
```

```bash
npm run build
```

WASD 移动，鼠标瞄准，左键 / 右键分别用两只手的枪射击，TAB 打开背包。完整的操作和玩法见游戏主菜单的“操作与玩法”。

## 开服联机

1. 房主完成上面的构建后运行 `npm run serve`，窗口里会显示本机的局域网地址，例如 `http://192.168.1.5:4056`。
2. 房主在浏览器打开 <http://localhost:4056>，点“联机游戏（局域网）”→“创建房间”，得到一个 4 位字母的房间号。
3. 队友在同一局域网的电脑上用浏览器打开房主的局域网地址，点“联机游戏（局域网）”，输入房间号加入。
4. 每人起好名字后，房主选择难度并开始游戏。

队友打不开地址时，请在房主电脑的防火墙里允许 Node.js 访问网络；不在同一个局域网时，可以用 Tailscale 等虚拟局域网软件把电脑连起来。
