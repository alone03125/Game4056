# 末日4056

根据《Game4056GP》策划案制作的 **俯视角 3D 类幸存者肉鸽网页游戏**，第2版按《第2版改动》加入了 **局域网 1~4 人联机**，第3次调整加入了隐藏的第六区与新 Boss。
在 4 个辐射区域中一路向上突围，靠沿途拾取的枪械、子弹与逻辑模块构筑武器，在安全屋里整备与升级，击败尸王「牢大丧尸」；如果在辐射进入橙色之前击败它，还能前往第六区「隐秘核心」挑战「曼巴僵尸」。

所有美术（模型、贴图、特效、图标）、音效与音乐均由代码实时生成；唯一的外部素材是界面字体：汉字使用 [缝合像素字体 Fusion Pixel Font](https://github.com/TakWolf/fusion-pixel-font)（SIL OFL 1.1 协议），数字与英文使用策划提供的 NoitaPixel。两者在构建前合并成一个字体，构建时只保留游戏里用到的字符并内嵌进页面，因此仍然可以离线运行。NoitaPixel 的版权属于 Nolla Games、没有开源协议，**不包含在公开仓库里**；没有它时构建自动只用 Fusion Pixel（见 [CONTRIBUTING.md](CONTRIBUTING.md)）。

## 如何游玩

### 单人

**最简单：** 打开 [在线试玩](https://alone03125.github.io/Game4056/)；或者在本地 `npm install && npm run build` 后，直接双击打开 `dist/Game4056.html`（单文件版，脚本已内联，可离线、可直接用 `file://` 打开）。

也可以启动本地服务器后访问 <http://localhost:4056>：

```bash
node serve.mjs
```

建议使用最新版 Chrome / Edge，并开启硬件加速。画面卡顿时可在「设置」里把画质调到「中」或「低」，画面太暗或太亮可以调「场景整体亮度」。

### 局域网联机（1~4 人）

1. 房主电脑安装 Node.js，在游戏目录运行 `node serve.mjs`。窗口里会打印本机的局域网地址，例如 `http://192.168.1.5:4056`。
2. 房主用浏览器打开 <http://localhost:4056>，点「联机游戏」→「创建房间」，得到一个 4 位英文字母的房间号。
3. 其他玩家（同一局域网）用浏览器打开房主的局域网地址，点「联机游戏」，输入房间号加入。
4. 进入房间后每人需要起一个名字；房主选择难度后点「开始游戏」。

如果其他电脑打不开房主的地址，请在房主电脑的防火墙里允许 Node.js 访问专用网络。联机必须通过服务器打开页面，直接双击 HTML 文件只能单人游玩。

### 操作（可在「设置」里修改键位）

| 按键 | 作用 |
| --- | --- |
| W A S D / 方向键 | 移动 |
| 鼠标 | 瞄准 |
| 左键 / 右键 | 主手 / 副手枪械射击（可同时使用） |
| Q / E | 主手 / 副手自动射击开关 |
| R | 提前换弹 |
| F | 拉起倒地的队友；拾取自己丢下的物品；与安全屋的祭坛、商店、防护服柜、医疗箱交互 |
| TAB | 打开背包，**同时暂停游戏**（联机时所有人一起暂停） |
| 1 ~ 7 | 快捷使用：止痛药、奶白金、过热模块、鳗、净化血清、零件1型、零件2型 |
| ESC | 暂停菜单 |
| 空格 / 鼠标点击 | 联机阵亡后观战时切换队友 |

背包内：拖拽子弹进枪的槽位即可装填，拖出面板即丢弃，右键为快捷操作（装填、装备、使用、卸下、丢下金币堆）。安全屋的「整备 / 出售」页还可以把物品拖到出售区。

## 已实现的策划案内容

### 初版

- **流程**：4 个大区域 + Boss 区。起点与安全屋位于区域对角；安全屋出入口都在房间角落，出口随机设在左上或右上角，从而决定下一区向左还是向右延伸。靠近出口时开始倒计时，结束后开门并开始新区域的探索计时；抵达新安全屋时立即关门，进入整备状态。
- **背包**：默认 16 单位；装在枪里的子弹单独储存并显示在对应枪械下方；枪械 4 单位、子弹 1 单位，金币可堆叠（每 1750 金币占 1 单位）；拖出背包丢到地上；拾取时背包图标闪烁；图标下方显示 x/x，剩余 ≤5 变橙、为 0 变红。
- **玩家**：初始血量 100、移速 4.0 m/s；接触伤害、远程攻击、辐射扣血；安全屋回满血。
- **刷怪**：区域生成之初少量敌人在全图均匀分布；之后从摄像机外持续生成，并根据玩家周围敌人过多或过少调节速率；类型判别使用权重池 + 临近降重；精英单位优先判定、无视临近降重，并保证场上精英不少于 10/14/18/22 个。
- **寻路**：全图流场追踪，丧尸始终追踪玩家（会绕开建筑）。
- **强化系数**：`max(1, log10(辐射值K) − 0.5)`，作用于新生成丧尸的生命与移速。
- **敌人**：社畜 / 头铁 / 跑得快 / 吐口水丧尸与牢大丧尸；区域倍率区间、生成权重、黄/橙/红变异概率与倍率、金币 × 区域值均按表格。吐口水丧尸会刻意与玩家保持距离并远程吐口水。
- **牢大丧尸**：碰（接触）+ 肘（蓄力冲刺，撞墙会眩晕）+ 丢（抛掷石块，落点有预警圈）；半血以下狂暴；2/3 与 1/3 血量时召唤精英尸群。
- **辐射**：每区每秒 +0.1/0.2/0.3/0.4K，不会自然下降；黄色仅提示，橙色每秒扣 0.3% 最大生命，红色每秒扣 3%。
- **子弹**：依次打出所有子弹、两发之间等待射击延迟、打完后换弹；子弹基础数值随机 0.7~1.4 倍；数值补正改变枪械数据。策划案中的「三发弹丸」「炸弹」按原例的机制实现，攻击力在平衡调整中上调（12 → 24、140 → 210）。
- **后坐力**：`(1/射击延迟) × 后坐系数`，<15 降低移速、15~30 持续向后推、>30 冲力位移；界面显示【轻松射击】【太空步】【肩胛粉碎者】标签。
- **道具**：每区随机位置 15 个，权重与效果按表格；安全屋：休息回满、金币与换金道具全部暂存、祭坛（花费 100→200→400→700→1100→… 跨区域继承）、商店（4 把枪 + 5 枚子弹，必有一把 Rarity3 以上，可刷新）。

### 第2版

- **局域网联机**：房主开服，其他玩家输入局域网网址打开网页、输入 4 位字母房间号加入、起名字。每名玩家在本地游玩自己的角色，定期把必要数据发给房主，由房主所在的服务器转发给所有人。
  - 玩家的子弹对玩家（包括自己的子弹，如炸弹）只造成 5% 伤害。
  - 生命归零会倒地；队友在倒地玩家身边按 F 并站立不动约 0.5 秒即可拉起，被拉起后恢复 30% 生命。倒地的玩家不再被丧尸追击，倒地时辐射照样累积。存活的玩家能在屏幕边缘和小地图上看到倒地队友的方向与距离。
  - 所有玩家都倒下则游戏结束；倒地玩家若没被拉起、队友就进入了下一个安全屋，会在本局阵亡并观战其他玩家。
  - 丧尸生成时按存活玩家数增加生命值：2 人 ×1.6、3 人 ×2.2、4 人 ×2.8（不含牢大）；牢大 2 人 ×2、3 人 ×3、4 人 ×4。
- **暂停**：TAB 打开背包的同时暂停游戏；联机时只要有 1 人暂停，所有人都会暂停，屏幕上提示「xxx 玩家正在暂停游戏」。
- **丧尸**：金币掉落 社畜 15、头铁 56、跑得快 25、吐口水 45；吐口水丧尸移速 3.0；口水弹的弹速（9 → 6）与弹丸大小（0.32 → 0.22）缩小，攻击距离 15 → 11 米。
- **拾取**：地图生成的道具经过即可拾取，不用按 F。金币吸取：单人模式全图吸取；联机时有约 12 米的吸取范围，并采用改动文档建议的方案：一个丧尸被任意队友打死，所有玩家都能吸取它的金币，击杀者获得全部，其他人获得 25%（金币在每个人本地各自生成，不会重复吸取）。
- **道具与商店**：大金币罐占 1 单位、兑换 2000 币；商店刷新 600；子弹价格 700~1700；枪械价格（稀有度+1）×700 ±1000。
- **辐射**：开始打 Boss 时（4 区结束后）辐射阈值固定为 240K、每秒 +0.5K，超过阈值直接受到红色级别伤害。每个安全屋里都有防护服柜，需要玩家手动拿取高一阶的防护服，不拿就不会提升阈值。
- **枪械**：`(稀有度+2)×1.75×(0.7~1.4) = 攻击倍率×(1/射击延迟)×(1/换弹延迟) + 最大载弹量`；载弹 2~10、射击延迟 ≤0.40s、换弹延迟 ≥0.40s、攻击倍率 ≥0.50x、散射 −40~40°；商店与地图的稀有度权重 1 区 50/40/10/0、2 区 30/40/20/10、3 区 20/30/30/20、4 区 10/20/40/30。名称和型号依照规律生成（见下文）。
- **客制化设置**：可以调整场景整体亮度与道具（及其他动作）的键位；游戏标题改为「末日4056」。
- **文案**：游戏内所有文字不再使用「·」，改用空格或逗号分隔。
- **子弹界面**：散射是坏属性，加大散射的子弹在散射一栏显示红色。所有来源的子弹（商店、地图、枪里自带）有 20% / 5% 概率成为 **闪耀** / **虹彩** 子弹，攻击力额外 ×1.25 / ×1.6，两者分别判定、可以叠加；界面中有闪光与彩虹流动的特效，射出的子弹也会发亮或变色。

### 第3次调整

- **界面**
  - 数字和英文换成 NoitaPixel（与汉字的像素字体合并，见下文）。
  - 自动射击的「AUTO」不会再被过长的枪名挤成省略号。
  - 主菜单背景中央不再出现穿模的玩家。
  - 图鉴按「子弹 / 逻辑模块 / 枪械 / 道具」分页，列出标准数值与装填后的数值变动。
  - 辐射条去掉状态文字，只在刻度线上标出阈值。
- **牢大丧尸**
  - 每个阶段 24000 生命，共 4 个阶段（3/4 血召唤精英、半血狂暴、1/4 血再次召唤）；生命条按阶段显示。
  - 投掷改为连续投石：每一块都锁定玩家当前的位置，预警到砸落的时间更短。
- **防护服**：第四区的安全屋也提供一次升级（V 级），阈值为黄 0（第五区始终是黄色级别）/ 橙 200 / 红 240K，取代原来「Boss 区固定 240K」的规则。
- **第六区「隐秘核心」**
  - 如果在辐射进入橙色之前击败牢大丧尸，尸王广场深处的安全屋会打开。这个安全屋没有祭坛、防护服柜和商店，但地上放着「玩家数 × 5」支净化血清（每支 −14K）。
  - 第六区辐射每秒 +0.6K，阈值不变。
  - Boss 是「曼巴僵尸」：24 万生命，攻击力 120（牢大 96）。技能有旋转激光（会被柱子挡住）、冲击波（玩家贴得太近时强制击退）、范围更大的连续投石、冲撞（狂暴后连续冲撞），每损失 1/5 生命召唤一批精英。
  - 击败曼巴僵尸是真结局。
- **数值**
  - 大金币罐兑换 3250 币。
  - 全局强化零件2型：所有枪换弹延迟 −0.15s（可保留）。
  - 下盘功夫：后坐力影响 −10%。
- **道具前缀**：地图中的强化血清（生命 / 脚力）、全局强化零件1型 / 2型、下盘功夫有 35% / 15% 的概率带有「高级」/「顶级」前缀，强化数额 ×1.25 / ×1.6，两者不叠加、顶级顶替高级。
- **Rarity5**：第三 / 四区地图中的随机枪械有 3% / 9% 的概率是 Rarity5（从 Rarity3 的权重中扣除），商店不出。
- **金币**
  - 携带的金币以金币堆的形式占用背包格子（每堆最多 1750、占 1 格），可以拖出背包或右键丢在地上腾出空间。
  - 丧尸掉落的金币不再乘区域值，改为乘强化系数 `log10(辐射值) − 0.5`（最低为 1），变异倍率照常相乘。
- **安全屋**
  - 进入时商店 / 祭坛面板不再自动弹出，可以亲眼看到被堵在门外的丧尸。
  - 生命值不再自动回满：走到防护服柜旁边的医疗箱按 F 回满。
- **枪械**
  - 硬下限：射击延迟不低于 0.05s、换弹延迟不低于 0.25s，无论经过多少强化。
  - **修饰语**：任何随机生成的枪名前面有 60% 的概率出现一个修饰语：

| 修饰语 | 效果 |
| --- | --- |
| 碎裂 / 粗劣 / 高端 / 神级 | 造成伤害 −30% / −10% / +10% / +30% |
| 强劲 | 子弹按造成的伤害击退丧尸；后坐力 +40% |
| 无情 | 换弹延迟 −0.15s；射击延迟 +0.05s |
| 危险 | 换弹延迟 +0.15s；射击延迟 −0.05s |
| 笨重 / 轻盈 | 装备时玩家移速 −15% / +20% |
| 残暴 | 造成伤害 +44%；射击延迟 +0.20s |
| 凶险 | 造成伤害 +44%；这把枪朝反方向发射子弹 |

### 第4次调整

  - 从第一区开始出现，每一区都从社畜丧尸的权重中挤占 3 点。

- **奶白金**：图标与模型改为中间有一颗星星的防暴盾牌。
- **其他**
  - 炸弹、地雷、毒雾弹、奇点弹和丧尸的口水会被奇点吸引，也会被爆炸推开。
  - 安全屋里可以手动开枪调试手感，不会伤害队友或自己。
  - 刚被拉起的队友有 4 秒无敌。
  - 鼠标准星更显眼。
  - 窗口失去焦点时自动静音（可在设置中关闭）。

## 策划案未规定、由我自行决定的部分

- **美术**：低多边形程序化建模（丧尸 4 种 + Boss + 防护服角色 + 根据枪械数据生成的枪械外观），程序化地面 / 墙体贴图，废墟街区程序化生成，每个区域不同的色调与氛围，粒子、泛光、动态光照、阴影、尸体倒地、血迹贴花。第2版加入安全屋的防护服柜（玻璃柜里的人台展示下一阶防护服）、队友的标识色光环与头顶名牌。
- **音频**：WebAudio 实时合成的全部音效与程序化音乐；第2版加入队友枪声（按距离衰减、带立体声）。
- **子弹设计**：共 25 种子弹（标准弹、穿透型黄铜子弹、重型铅弹、三发弹丸、鹿弹、炸弹、三级火箭、弹跳弹、追踪飞镖、燃烧弹、液氮弹、电弧弹、分裂弹、圆锯片、回旋镖、感应地雷、毒雾弹、轻量化弹头、钨芯穿甲弹、环形弹幕、等离子射线、奇点弹、吸血弹、招财弹、喷射推进弹）。
- **逻辑模块**：设计成类 Noita 的修饰法术，装在枪的槽位里、作用于排在它后面的子弹：双重/三重施放、追踪、穿透、爆裂、增幅、加速、聚焦，共 8 种。
- **枪械命名规律**（第2版）：名称 = 代号 + 类别。代号按稀有度分档（R1 是「打工人、保温杯」这类，R4 是「黑曜石、断头台、审判日」这类）；类别由数据决定（射速快且载弹多是转轮机枪，散射大是霰弹枪，攻击倍率高是狙击枪……）。型号 = 类别代码 + 厂商字母 − 稀有度 + 载弹量，例如 `SMK-47` 表示冲锋枪、K 厂、Rarity4、7 发。
- **联机的细节**：
  - 房主的浏览器负责丧尸与 Boss 的 AI、刷怪、地面道具归属与流程推进；其他玩家看到的丧尸来自房主每秒 20 次的快照（本地做平滑与外推），自己的子弹在本地判定命中后把伤害发给房主结算，因此射击手感没有延迟。
  - 每名玩家的背包、金币、祭坛、商店、辐射、防护服都各自独立；地面上的物品由房主裁决归属，同一件物品不会被两个人同时捡到。自己丢下的物品需要按 F 才能捡起（队友也可以捡），用来给队友送装备或金币。
  - 所有站着的玩家都进门后安全屋才关门；先到的玩家在门内等待（不会受伤、丧尸也不再追他）。若此时有队友倒在门外，会先倒计时 5 秒再关门，给大家回去救人的机会。离开安全屋的倒计时需要所有人都站到出口的黄色区域。
  - 联机时刷怪速率与场上上限额外乘以 1.2 / 1.4 / 1.6（2/3/4 人），并按每名玩家周围的密度分别判断，避免人多时每人分到的丧尸和金币太少。精英保底数量每多一人 +15%。
  - 友伤：同一名玩家受到友伤后有 0.5 秒的友伤无敌时间（独立于丧尸的受击无敌）；爆炸的友伤随距离衰减，中心 5%，边缘 1%。
  - 每人一次只能从防护服柜拿一件（高一阶的）防护服；第3次调整后第四区的安全屋提供最后一次（V 级）。
  - 房主离开会解散房间；一局结束后房主可以带大家回到房间重新开始。
- **第3次调整的细节**：
  - **字体**：NoitaPixel 只替换数字、英文字母和 ASCII 符号（`~` 除外，它在 NoitaPixel 里是占位字形）。NoitaPixel 的 1 个像素放大为汉字字体的 2 个像素（12px 字号时为 2 个屏幕像素），并下移 1 像素与汉字对齐。所有字号统一为 12 的倍数，两种字形都保持清晰。
  - **前往第六区的判断**：在牢大倒下的那一刻进行，要求所有未阵亡玩家的辐射都低于各自防护服的橙色阈值。满足时其余丧尸一同倒下、停止刷怪，看台后面的安全屋开门；不满足则直接胜利，结算页会提示这条隐藏路线。
  - **结算与战绩**：击败牢大即算通关；击败曼巴单独记录次数，结算显示「真 · 突围成功」；击败牢大后在隐秘核心倒下，结算为「倒在隐秘核心」，仍算通关。
  - **曼巴僵尸**：生命与牢大一样乘难度和联机人数倍率。技能细节：
    - 激光同时 2 道（狂暴 3 道），旋转约 4~5 秒，开始时避开正对玩家的方向。
    - 冲击波在玩家进入约 7 米时蓄力 0.55~0.75 秒后爆发，即使在无敌时间内也会被推开。
    - 模型是紫金配色、更大一圈并拖着蛇尾的「牢大」。
  - **第六区**：72 米见方的场地，外圈 10 根柱子，内圈 4 根矮柱可以挡激光。丧尸比第五区更强、更多。
  - **金币的强化系数**：按每个玩家自己当前的辐射值计算（联机时房主只发送基础金币，各人在本地乘自己的系数）。
  - **医疗箱**：可以反复使用；倒在门外、被关进安全屋的队友至少恢复 30% 生命。
  - **修饰语**：开局武器没有修饰语。「笨重 / 轻盈」在主手或副手装备时生效，两把都有时相加。「强劲」的击退力度为 `min(12, 1 + 伤害/25)`。「凶险」从身后射出子弹，后坐力也随之反向，变成向前推。
  - **快捷键**：同类道具有多个时，优先使用前缀等级高的。
- **第4次调整的细节**：
  - **盲盒**：可以变成除盲盒以外的任何子弹（不含逻辑模块），本身不会是闪耀 / 虹彩。HUD 的「下一发」后坐力显示为【随机】。
  - **黄油**：晕眩半径约 1.8 米；晕眩的丧尸不能移动、攻击和吐口水；Boss 免疫晕眩。联机时由房主结算晕眩。
  - **苦力怕**：靠近到约 2.2 米时点燃，爆炸半径 3.2 米（精英大一圈）。点燃后一边闪白一边膨胀并发出嘶嘶声。被点燃后再被打死，仍然按「提前打死」给 34 金币。金币与其他丧尸一样乘变异倍率和强化系数。爆炸殃及的丧尸记在引爆它（或打死它）的玩家名下。
  - **观战数据**：每名玩家定期把自己的枪、快捷栏道具数量、背包与金币发给队友，手上的射击 / 换弹状态随玩家状态每秒发送 20 次。小地图上的箭头也跟随被观战的队友。
  - **受力的投掷物**：Boss 的石块不受影响，保证落点预警圈准确。
  - **安全屋试枪**：只有手动射击生效（自动射击在安全屋里暂停），子弹直接穿过队友，打不到门外的丧尸；离开安全屋时清掉试枪留下的子弹和地雷。
  - **拉起无敌**：以「无敌」增益的形式显示在状态栏，期间也不受辐射伤害。
- **界面**：像素风字体（12px 设计，所有字号取 12 的倍数）；游戏内文字只保留对玩家有用的信息（随机范围、概率、价格公式等设计数值只写在本文档与开发文档里）。主菜单、单人游戏、联机房间（房间号、局域网地址、玩家列表、名字、难度）、暂停、设置、操作与玩法说明、图鉴（子弹 / 模块 / 枪械 / 道具的标准数值）、结算（联机时显示全队）、本地战绩；HUD（生命、辐射条、探索计时、强化系数、带迷雾的小地图、双枪面板、快捷栏、Boss 血条、连杀、方向指示、伤害数字、队友列表、倒地与观战提示）；小窗口自动缩放界面。
- **设置**：音量、画质、亮度、镜头距离、屏幕震动、伤害数字、帧率显示（联机时附带延迟）、操作提示、失焦自动暂停（仅单人）、键位。
- **额外系统**：Q/E 自动射击、R 提前换弹、出售物品（约三成价格）、拾取枪械时若有空手则直接装备、精英丧尸小概率掉落子弹。

## 平衡性调整说明

我写了一个自动游玩 AI（`src/debug/bot.ts`），用无头模拟（`tools/sim.ts`、联机用 `tools/mptest.ts`）跑了大量对局来调整数值。为了让游戏可玩，以下内容在策划案基础上做了调整或补充：

| 项目 | 处理 |
| --- | --- |
| 丧尸移速 | 策划案中社畜丧尸（4.6）比玩家（4.0）还快，玩家完全无法拉扯，所以统一乘以 0.58 |
| 接触伤害 | 丧尸贴身 0.3 秒后才出手，每只丧尸 1.2 秒冷却，玩家受击后有 0.5 秒无敌，避免被包围瞬间秒杀 |
| 区域伤害乘区 | 策划案提到「随区域乘区变化」但未给数值，取 1.0 / 1.15 / 1.3 / 1.45 |
| 子弹伤害 | 策划案只有两个例子，其余子弹由我设计；整体伤害水平按「割草」手感调整 |
| 难度 | 简单 / 普通（敌人生命与伤害 ×0.8，推荐首次游玩）/ 困难（策划案原始数值）/ 噩梦 |
| 刷怪密度 | 各区「周围敌人过少 / 过多」的阈值逐区提高，区域刚开始时刷怪较缓，随后逐渐加压 |
| 后坐力减速 | 按策划案公式计算，但实际减速上限为 85%（否则接近阈值时几乎无法移动） |
| Boss 区 | 使用第 4 区的敌人构成，但刷怪量较少；辐射阈值第2版固定为 240K，第3次调整改为 V 级防护服的 0/200/240K |
| 连续投石 | 预警到砸落 0.72~1.05 秒（原来 0.95~1.45 秒）：以初始移速一直跑动刚好能躲开，站着不动必中；曼巴的大石块 0.85~1.15 秒 |
| 第六区 | 生命 2.2~4.4 倍、伤害乘区 1.55、刷怪 1.5 只/秒（上限 90）、精英保底 8 |
| 联机人数 | 生命倍率按第2版表格；刷怪数量另乘 1.2/1.4/1.6，使丧尸总血量约等于人数 × 单人水平 |
| 友伤 | 5% 按第2版；另加 0.5 秒友伤无敌与爆炸距离衰减，避免自己的火箭在身边连续爆炸时伤害过高 |
| 感应地雷 | 敌人靠近触发后延迟 0.5 秒才爆炸，给玩家离开的时间，不会每次都炸到自己 |

## 开发

完整的开发流程（设计、代码、美术、音乐、调试）记录在 [docs/开发流程.md](docs/开发流程.md)。

```bash
npm install          # 安装依赖（three.js、esbuild、TypeScript、字体裁剪用的 subset-font）
npm run build        # 构建到 dist/（index.html + game.js，以及单文件 Game4056.html；同时裁剪并内嵌像素字体）
npm run dev          # 监听源码自动构建
npm run serve        # 本地服务器 + 联机房间服务 http://localhost:4056
npm run typecheck    # TypeScript 类型检查
npm run sim -- 8 normal      # 无头平衡模拟（AI 自动游玩 8 局）
npm run flowtest -- 6        # 流程测试：无敌 + 无敌人，验证全部区域都能走通（FAST=1 时 Boss 自动掉血，只测流程）
npm run bosstest -- 6        # Boss 战测试（ZONE=6 打曼巴僵尸，GOD=1 无敌，用来测击杀用时）
npm run mptest -- 3 normal   # 无头联机测试：3 个 AI 玩家通过内存中转联机（GOD=1 无敌，LAT=0.05 模拟延迟，LOWRAD=1 测试隐秘核心路线）
npm run modtest              # 规则测试（第3、4次调整：修饰语、硬下限、道具前缀、Rarity5、金币公式、盲盒、黄油、苦力怕、奇点吸引、安全屋试枪…）
npm run font                 # 重新生成合并字体 assets/fonts/pixel4056.ttf（需要本地有 NoitaPixel、Python 与 fontTools）
```

调试用 URL 参数（单人）：`?bot=1`（AI 自动游玩）、`?zone=3`（直接跳到第 3 区）、`?safe=1`（配合 zone 进入安全屋）、`?god=1`（无敌）、`?gold=20000`（给金币）、`?seed=123`。联机时加 `?bot=1&mp=1` 可以让 AI 操作本页面的玩家。

## 未完成 / 已知限制

- 没有局内存档（关闭页面即结束本局；设置与战绩会保存在浏览器本地）。
- 联机：只支持局域网（或其他能直接访问房主电脑的网络）；房主断线会解散房间，不支持中途加入、断线重连与更换房主；没有防作弊（每个人的数据在本地结算）。
- 平衡性主要依靠 AI 模拟调整，AI 的走位明显不如真人，联机时 AI 之间也不会配合，实际体验可能偏简单或偏难，可通过难度选项调节。
- 只支持键鼠操作，不支持手柄和触屏。
- 像素字体只内嵌了游戏文字里用到的字符；玩家名字里的其他字符会用系统字体显示。
- NoitaPixel 字体由策划提供，版权属于 Nolla Games，没有附带开源协议，所以没有放进公开仓库；在线试玩版和别人从仓库构建的版本，数字和英文都是 Fusion Pixel 的字形。
